# Goa, slowly.

A responsive, single-page sample Goa tourism website built with Bootstrap 5.3.3, custom CSS, and vanilla JavaScript.

## Open locally

Start Apache in XAMPP, then visit **http://localhost/goa-tourism/**. No build, package installation, or database is required. You can also open `index.html` directly.

## Features

- Responsive Bootstrap navigation and layout
- Destination filters and detail modals
- Sample itineraries for three travel styles and two, three, or five days
- Travel tips in a Bootstrap accordion
- Local Bootstrap and photography, with photo credits in the page
- Keyboard focus styles and reduced motion support

## Files

- `index.html`: page content
- `assets/css/style.css`: coastal theme and responsive styles
- `assets/js/main.js`: filters, destination details, and itinerary generation
- `assets/vendor/`: Bootstrap CSS and JavaScript with upstream license headers
- `assets/images/`: sample photography

The trip planner generates illustrative suggestions in the browser; it does not make bookings. This independent demo is not affiliated with Goa Tourism. Image sources are listed in the page’s Photo credits dialog; confirm permission for any use beyond this sample.
